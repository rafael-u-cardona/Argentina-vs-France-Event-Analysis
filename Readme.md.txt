# Argentina vs France - FIFA World Cup 2022 Final Event Analysis

## Overview

This project analyzes the FIFA World Cup Qatar 2022 Final between Argentina and France using StatsBomb Open Data and Python.

The analysis focuses on:

- Event exploration
- Shot analysis
- Goal analysis
- Expected Goals (xG)
- Player performance
- Team performance


## Dataset

Source:
StatsBomb Open Data

Match ID:
3869685

Fixture:
Argentina vs France

Competition:
FIFA World Cup Qatar 2022


## Technologies Used

- Python
- JSON
- Pandas
- Matplotlib
